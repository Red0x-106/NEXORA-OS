# NEXORA OS

NEXORA OS is a browser-based desktop OS that I made using HTML, CSS and JavaScript.

I wanted to make a mini desktop that could run on webpages..

## What is NEXORA OS?

NEXORA is a mini desktop type site where there are some apps to use and explore.

It has:

- A desktop
- A top bar
- A bottom dock
- Different wallpapers
- Apps
- Draggable windows
- Minimize, maximize and close buttons

## Features

Some of the features I added are:

- Desktop app icons
- Date and time
- Draggable windows
- Minimize, maximize and close buttons
- Different wallpapers
- Calculator
- Notes
- Files
- Browser
- Settings
- Themes
- Saved notes
- Code viewer
